A short poem about agency — the power to choose and to act — in the moment
two agents agree on one plan. Two maps on a table, a third road drawn where
they disagree, and a key that turns in both hands at once.

Run it with:

```sh
python3 main.py
```

It deterministically writes the poem to `/output/entry.txt` and prints it.
